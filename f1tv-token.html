F1TV Token Capture

Deliver your F1TV token to the F1 Sensor integration. The token is sent only to this Home Assistant and is never stored.

1Start a pairing session

Settings → Devices & services → F1 Sensor → Reconfigure → Connect F1TV access with Token Helper → Open website. Copy the full URL of the page that opens and paste it here. Sessions last 5 minutes.

2Paste your F1TV token

Accepts the JWT itself, a Bearer … header, the login-session cookie value, or the cookie JSON.
Needs the companion extension and an F1TV sign-in.
Notes and getting the token manually
  1. The Capture button needs the companion extension (extension/ folder, see README). Browsers don't let a web page read another site's login, so the extension does that one step.
  2. Manual alternative: sign in at f1tv.formula1.com, open developer tools → Application (Chrome/Edge) or Storage (Firefox) → Cookies → copy the value of login-session and paste it above. The page extracts subscriptionToken from it.
  3. Treat the token like a password. Don't post it in issues or screenshots.
  4. If this page isn't served from your Home Assistant (e.g. opened from disk), the browser will block the send. Host it under /config/www/.
