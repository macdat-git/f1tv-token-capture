# Privacy

F1TV Token Capture collects, stores and transmits nothing.

- **What it reads:** cookies for `formula1.com` in your own browser, only when you click the button (or, on a page you host at `/local/f1tv-token…`, when that page asks).
- **What it does with them:** extracts one token and puts it on your clipboard (or, for the optional dashboard page, hands it to that page in the same tab).
- **Storage:** none. The extension keeps no data between uses.
- **Network:** the extension makes no network requests. Only if you use the optional dashboard page's *Send to Home Assistant* button does the token go to your own Home Assistant server.
- **Analytics / third parties:** none.
- **Opening F1 TV:** the popup's "Open F1TV to sign in" link opens `https://f1tv.formula1.com/` in a new tab, only when you click it.
